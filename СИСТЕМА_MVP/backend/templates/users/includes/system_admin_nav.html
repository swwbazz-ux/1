{% comment %} Разделы админки — одним списком на все страницы. Раньше навигацию переписывали в каждом шаблоне отдельно, и списки разошлись: где семь кнопок, где восемь, где девять. Из-за этого шапка на разных вкладках получалась разной высоты, и при переходе страница подпрыгивала. Новый раздел приходилось дописывать в десять файлов, о части из них забывали. Активную вкладку определяем по адресу, а не по переменной из вьюхи: иначе каждую вьюху пришлось бы помнить и править. {% endcomment %}
