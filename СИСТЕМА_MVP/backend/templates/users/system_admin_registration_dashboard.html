Как считаются показатели

Доступ подготовлен — по всем требуемым ролям есть действующий персональный доступ: PIN сформирован или доступ уже активирован; готовые сотрудники также входят в этот этап. Готов к работе — сотрудник активировал доступ для каждой рабочей роли, требуемой выбранной расстановкой. Установка PWA или APK пока не фиксируется отдельно; после появления достоверного события первого запуска будет добавлен самостоятельный показатель.
