# Пакет проверки транспорта команд диспетчера и горного мастера

Пакет исполняет функции из релизного SHA
`0fe60543de59bf7cbeca4868fc17e8e00689d2ba`:

- `static/js/dispatcher-transport-v1.js` — транспорт диспетчера;
- inline-функции очереди из `templates/trips/dispatcher_control.html` — транспорт
  горного мастера.

Запуск из PowerShell:

```powershell
& .\run.ps1 -ReleaseWorktree C:\codex-tmp\passport-proof-rel-0fe605
```

Проверка специально останавливается, если HEAD переданного worktree не равен
зафиксированному SHA. Реальная серверная база и установленное приложение не
используются. Потеря ответа после принятия моделируется и в выводе помечена
`MOCK`; свойства установленного телефона помечены `NOT_RUN`.
