## 2. Исправление C1/C2

Адаптер и раньше собирал исходные receipts, доказанно относящиеся к рейсу через
область `(authenticated actor, device, local_trip_id)`. Теперь выборка
`OfflineFieldEventConflict` дополнительно включает строки, у которых
`existing_event_id` входит именно в этот уже доказанный набор receipts.

Происхождение не теряется:

- прямой конфликт сохраняет `direct_trip_reference`;
- конфликт, найденный через исходный receipt, получает
  `original_receipt_direct_trip_reference` либо
  `original_receipt_resolved_local_trip_reference`;
- конфликт по local-ссылке предъявленного повтора сохраняет
  `resolved_local_trip_reference`.

Область автора/устройства не ослаблена. Один текст `local_trip_id` не связывает
рейс. Неоднозначное отображение нескольких рейсов остаётся неоднозначным.
Добавлены две отрицательные регрессии: чужой actor/device и неоднозначная
локальная связь не подтягивают конфликт через исходный receipt.

## 4. Переносимость хешей

R2-runner не читает probes из рабочей копии. Он получает точные Git blobs из
commit `834539b…` через `git rev-parse`/`git cat-file`, проверяет одновременно
blob OID и SHA-256 опубликованных bytes и только затем записывает эти bytes во
временную папку для запуска.

Фактически проверены LF Git blobs:

- `probe_adapter.py`: blob `9b02c502…`, SHA-256
  `05573f69d16913516c0273ee461890e6f65aa9e8cfa97f89d37b2e7e0a1f9b5f`;
- `probe_load_origin.py`: blob `f1ff9609…`, SHA-256
  `6302543320ada0674c2d7702572c4fd9cd929b1d31453908c0996440fe999a4a`;
- `probe_local_conflict.py`: blob `57001ac9…`, SHA-256
  `caabf74cf3633bda47aa171d4b41497f29facd277523a73cc5190cef0d22fa81`.

Во всех трёх blobs `CRLF=0`; ручное LF→CRLF-преобразование не выполняется и не
требуется. Исторические I2/I2-R1 пакеты не редактировались.

После первой публикации документации отдельная проверка manifest должна быть
выполнена по точному опубликованному commit; её JSON и второй документационный
commit добавляются как завершающее доказательство без изменения кандидата.

## 5. Среда и ограничения

Фактическая среда: Windows, Python 3.12.10, Django 6.0.6, изолированная SQLite
`:memory:`, LocMem cache и временный media-root. Унаследованные параметры
внешней БД удаляются runner-ом; `.env` в кандидате запрещён.

**NOT_RUN:** PostgreSQL, конкурентные writer-процессы, DOM, телефон, native
audio, production. Эти границы не подменяются общим зелёным результатом.

Адаптер остаётся неподключённым: рабочее приложение не читает его вывод и не
меняет на его основании рейсы или экран.
