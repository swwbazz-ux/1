# Публичный каталог готовых PWA

Дата: 23.08.2026 (Владивосток).

## Цель

Подготовить простой первый шаг для офисного тестирования диспетчерского и
других уже готовых модулей: сотрудник открывает одну общую страницу, выбирает
своё приложение по крупной иконке и получает корректный путь к установке PWA.

## Реализованный контракт

Публичный каталог доступен по маршруту `/apps/` общего домена. В нём строго
восемь согласованных приложений:

1. Горный диспетчер.
2. Машинист экскаватора.
3. Водитель самосвала.
4. Горный мастер.
5. Заместитель начальника участка.
6. ОУП.
7. Руководство.
8. Системный администратор.

Делопроизводитель, Табельщик, Начальник участка и Механическая служба в каталог
не включены. Их наличие во внутреннем реестре ролей не означает готовность к
выдаче сотрудникам.

На компьютере и планшете выбор иконки открывает центральное окно с локально
сформированным QR-кодом, прямой ссылкой, копированием и кнопкой открытия. На
телефоне выбор сразу открывает ролевой поддомен, чтобы не добавлять лишний шаг.
Без JavaScript каждая карточка остаётся обычной рабочей ссылкой.

На ролевом экране входа добавлена явная кнопка «Установить приложение». Она
использует штатное событие браузера `beforeinstallprompt`, не запускает
установку без действия сотрудника, распознаёт уже установленный режим и даёт
ручную инструкцию для Android/iPhone, если браузер не выдал системное окно.

Каталог не объявляет себя PWA и не регистрирует service worker. Ссылка на него
с каждого ролевого поддомена ведёт на общий origin; прямое открытие `/apps/`
внутри ролевого origin также перенаправляется на общий домен. Поэтому каталог
не попадает внутрь корневой области установленного приложения конкретной роли.

QR формируется сервером средствами уже имеющегося `reportlab`. Внешние QR-
сервисы не используются, адреса приложений третьей стороне не передаются.

- `makemigrations --check --dry-run`: `No changes detected`;
- `git diff --check`: успешно;
- Browser QA: `1280×720`, `768×1024`, `390×844`;
- на всех размерах: восемь карточек, отсутствие горизонтального overflow,
  читаемые подписи и рабочие действия;
- QR загружен как SVG `256×256`, модальное окно и прямая ссылка совпадают;
- мобильный переход открывает правильный ролевой login с manifest и кнопкой

- ролевой каталог перенаправляется на общий origin;
- ошибок и предупреждений браузерной консоли нет.

Локальный сервер после проверки остановлен. Изолированная SQLite возвращена к
исходному пустому состоянию, порт `8000` свободен. Рабочая база проекта,
`.env`, миграции и реальные данные не затрагивались.
