# Доказательства приёмки P28-I1

Источник: `swwbazz-ux/1`, docs commit `64f900b588c8dece9b7d4741a07fa2287d82bb88`. Исходный пакет `ПАКЕТ_P28_I1_2026_09_28` не изменён.

- `hash-verification.log` — 7/7 опубликованных SHA-256 совпали.
- `root-replay.log` — собственный прямой Python-прогон 22 тестов, exit=0; stdout включает маршрутные трассы. Пустые env-маркеры в этом replay не являются содержимым исходного raw Кодекса. Источник установлен через Git blob и manifest.
- `counterexamples.py` — адресные дополнительные ожидания C1/C2 и наблюдение C3.
- `counterexamples.jsonl` — 3 нарушения ожиданий на исходном I1, exit=1; C3 отдельно показывает равенство направления при различном аудите. Это не новая версия исходных 22 тестов.
- `SHA256SUMS.txt` — хеши файлов этой приёмки; не заменяет manifest исходного пакета.

Из корня репозитория с неизменным исходным пакетом:

```bash
python ПРОГРЕСС_ПРОЕКТА/ДОКАЗАТЕЛЬСТВА_ПРИЕМКИ_P28_I1_2026_09_28/counterexamples.py --package ПРОГРЕСС_ПРОЕКТА/ПАКЕТ_P28_I1_2026_09_28
```

На I1 ожидается exit=1. Сохранённость входной записи проверяется после сериализации и восстановления, не только по хешу. Проверка C1b адресована коллизии одного ID между X/Y; C2 использует честный `history_complete=False`. Ни один пример не требует сети, БД или неаутентифицированного UI.

Полный вывод и следующее поручение — [приёмка P28-I1](../ПАСПОРТ_МЕХАНИК_ПРИЕМКА_P28_I1_2026_09_28.md). NOT_RUN: PowerShell в Windows, SQLite/PostgreSQL, Django, DOM, телефон/native audio.
