# Приёмка P28-C1-R1 и точные хеши

Астра, 28.09.2026. Это дополнение к исходному README, тестам и журналу commit `8344afbf13f9cc10e07fee2b76a7c8537bd37c91`; они сохранены без изменений.

`SHA256SUMS.txt` содержит хеши точных опубликованных UTF-8/LF-байтов. Исходный перечень сохранён в `SHA256SUMS.windows-original.txt`: его пять хешей совпадают с восстановленными CRLF-копиями этих файлов, но не с Git blobs. Содержимое Windows-диска напрямую не проверялось. `hash-verification.log` показывает исходный/вычисленный SHA-256 и независимое совпадение Git SHA-1.

Состоявшийся прогон: SQLite, 10 тестов OK, exit 0; новый прогон не выполнялся. Сохранены исходные тесты, README, runner и UTF-8 raw. PostgreSQL, DOM и телефон NOT_RUN.

**Ограничения покрытия:** все операции свободного ковша в R1 делает один экскаватор; offline «на/после границы» на деле вызывается после принудительного reconcile будущим временем; некоторые точные коды и поля только напечатаны. Настоящие серверные builders исполнены в отдельных точках истории, но полной проверки всех значений на каждом рабочем месте нет. UNCONTROLLED в отказном тесте также подготовлен fixture, поэтому фраза исходного README «прямые записи только recorded=true/false» неполна. Полная таблица приёмки — § 33 [общего разбора](../ПАСПОРТ_МЕХАНИК_РАЗБОР_РЕЦЕНЗИИ_РОЛИ_2026_09_28.md).

**Повторный запуск:** исходный `run.ps1` перезаписывает `raw-run-utf8.log`. Для нового прогона сначала сделайте отдельную копию пакета и сохраняйте новый журнал отдельно; не подменяйте опубликованный исходник. Проверки Python-входа и допустимого vendor не являются самостоятельным безопасным PG gate. Подключение к постоянной БД и установка новой среды этим пакетом не поручаются.

Ограниченное исследование принято как основа проектирования. Пропущенные разные экскаваторы, согласованная шкала offline-времени и точные проекции остаются обязательными проверками будущего кандидата, а не получают PASS задним числом.
