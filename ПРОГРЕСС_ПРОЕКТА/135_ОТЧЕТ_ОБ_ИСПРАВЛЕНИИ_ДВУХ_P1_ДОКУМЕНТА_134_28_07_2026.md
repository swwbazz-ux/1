## 3. QA-REG-P1-DRIVER-LOGOUT-HOLD-001

### 3.1. Воспроизведение и причина

Исполняемый тест настоящего блока из
`templates/users/driver_shift.html` воспроизвёл:

```text
ReferenceError: holdMs is not defined
at drawLogoutHold
```

`drawLogoutHold()` использовал `holdMs`, но эта переменная существовала только
в других вложенных функциях и не входила в лексическую область обработчика
кнопки `Выйти`.

### 3.2. Исправление

В logout-handler введена собственная локальная константа:

```javascript
const logoutHoldMs = 2000;
```

Расчёт прогресса использует только её. При достижении `100%` активное состояние
и идентификатор animation frame обнуляются до единственного перехода на
`/logout/`.

Logout намеренно не переведён на `createDriverRoleHoldGuard`: этот guard
блокирует завершение при неактивной роли, а безопасный выход из старой
read-only PWA должен оставаться доступен.

Серверный запрет изменяющих действий при неактивной роли не менялся.

### 3.3. Новая исполняемая регрессия

Создан:

```text
static/js/tests/driver-logout-hold-runtime.test.js
```

Тест извлекает настоящий production-блок из шаблона и проверяет:

- полное удержание выполняет ровно один переход на `/logout/`;
- обработчик можно использовать повторно;
- ранний отпуск сбрасывает прогресс и не выполняет переход;
- logout остаётся доступен при `role_active=false`;
- после завершения не остаётся animation frame.

До исправления: `0/3`, все три сценария завершались тем же
`ReferenceError`.

После исправления: `3/3 PASS`.

## 4. QA-REG-P1-DISPATCHER-MOBILE-EMPTY-001

### 4.1. Воспроизведение и причина

Desktop-правило:

```css
.dispatcher-board.is-excavator-garage-empty
```

имеет specificity `0,2,0` и сохраняло трёхколоночную сетку. Более позднее
мобильное правило `.dispatcher-board` имело specificity `0,1,0` и не могло его
переопределить.

При одновременном классе `is-truck-garage-empty` правая колонка также
становилась нулевой. Mobile topbar и рабочая область назначались в первую
нулевую колонку.

Исходное живое состояние документа 134:

```text
columns:          0px 378.4px 0px
topbar width:     1.6px
zone-grid width:  2px
```

### 4.2. Исправление

Только внутри `@media (max-width: 1180px)` добавлен combined-state selector:

```css
.dispatcher-board.is-excavator-garage-empty.is-truck-garage-empty
```

Он:

- переводит board в одну колонку `minmax(0, 1fr)`;
- возвращает штатный межколоночный отступ;
- удаляет desktop-отступ скрытого левого гаража у комплексов.

Первый Browser QA после восстановления ширины выявил ещё одну часть того же
дефекта: desktop-ограничение верхней панели `108px` обрезало mobile header, и
навигация оказывалась под карточками.

Для того же combined-state mobile selector высота unified topbar и
`dispatcher-header-row` переведена в фактическую высоту содержимого:

```css
height: auto;
min-height: 0;
max-height: none;
```

Правило не действует на `1280px` и не меняет другие состояния пульта.

### 4.3. Новая исполняемая регрессия

Создан:

```text
static/js/tests/dispatcher-mobile-empty-garages-runtime.test.js
```

Проверяются:

- одноколоночная mobile-сетка при обоих пустых гаражах;
- сброс desktop-отступа complexes;
- снятие фиксированной высоты topbar/header, чтобы навигация не обрезалась.

До первого исправления: `0/2`, оба обязательных mobile selector отсутствовали.

После первого исправления Browser QA воспроизвёл обрезание навигации; новая
третья регрессия дала `2/3`.

Финальный результат: `3/3 PASS`.
