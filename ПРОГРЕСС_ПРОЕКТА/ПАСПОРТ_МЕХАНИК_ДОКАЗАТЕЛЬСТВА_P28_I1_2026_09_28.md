## 2. Что реализовано

Pure-Python ядро принимает нормализованные неизменяемые события одного рейса, строит причинный граф и сначала выбирает причинные максимумы. Только после этого применяется узкое утверждённое правило P28-В3: при ровно одной независимой команде водителя и одной машиниста действует водительская.

Реализованы:

- сохранение первого содержания ID и диагностика несовместимого повтора;
- fingerprint бизнес-содержания без receipt time;
- отдельные action time и receipt time;
- ожидание отсутствующего предка без выдуманной независимости;
- обнаружение цикла;
- защита от cross-trip причинной связи;
- `policy_unresolved` для неутверждённых множественных максимумов;
- сохранение автора/идентичности исходной погрузки отдельно от автора маршрута;
- отдельная жизненная проекция: технический `UNCONTROLLED` не равен разгрузке, а доказанные CANCELLED/unloaded/superseded подавляют только оперативный показ и будущий notification key;
- notification key по выбранному событию, а не общей версии снимка;
- snapshot/restart модели без заявления о долговечности телефона.

Открытые производственные правила не подменены. В частности, две независимые команды одной роли остаются `policy_unresolved`.

## 3. Выполненная команда и результат

Команда из корня документационного worktree:

```powershell
& '.\ПРОГРЕСС_ПРОЕКТА\ПАКЕТ_P28_I1_2026_09_28\run.ps1' -DocsRoot (Get-Location).Path
```

Фактический исход:

- `P28_I1_TESTS_RUN=22`;
- `P28_I1_FAILURES=0`;
- `P28_I1_ERRORS=0`;
- `P28_I1_EXIT_CODE=0`;
- одна фиксированная четырёхсобытийная история проверена во всех 24 порядках доставки;
- raw: [raw-run-utf8.log](ПАКЕТ_P28_I1_2026_09_28/raw-run-utf8.log).

Входы и ожидаемые исходы перечислены до результата в [README](ПАКЕТ_P28_I1_2026_09_28/README.md); причинное обоснование — в [CONVERGENCE.md](ПАКЕТ_P28_I1_2026_09_28/CONVERGENCE.md).

## 4. Подтверждённые свойства

| Группа | Фактический результат |
|---|---|
| Независимые D/O | В обоих порядках выбран D; история обоих сохранена |
| Причинное O после D | До предка — неполнота; после полной доставки выбран O |
| Перестановки | 24/24 дают одинаковую конечную проекцию |
| Повтор/restart | Одна запись; та же проекция после snapshot restore |
| ID/fingerprint/цикл/missing parent | Явная диагностика без замены оригинала и без выдуманного победителя |
| Неутверждённые пары одной роли | `policy_unresolved` |
| Технический таймер | `technical_uncontrolled` не создаёт разгрузку |
| Завершение/замещение | История сохранена; оперативный показ и notification key отсутствуют |
| Legacy actual без происхождения | Новое действие водителя не синтезируется |
