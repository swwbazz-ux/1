# Git-scope аудит недельного и трафикового ready-core

Дата фиксации: 28.07.2026.

Статус: **АУДИТ ПРОЙДЕН / ПАКЕТ РАЗРЕШЁН К COMMIT И PUSH / DEPLOY И
PRODUCTION ЗАПРЕЩЕНЫ**.

## 1. Основание

Владелец проекта разрешил:

- провести Git-scope аудит принятого локального пакета;
- создать один локальный commit;
- выполнить обычный push в ветку
  `codex/ready-core-pilot-2026-07-27`.

Deploy, production, рабочая база, `.env`, миграции, nginx, systemd и
`collectstatic` этим разрешением не затрагиваются.

## 2. Исходная точка Git

- ветка: `codex/ready-core-pilot-2026-07-27`;
- HEAD: `26ad7a9f5b570e20be52e131ad4e1d39a984602f`;
- после `git fetch origin --prune` локальный HEAD и
  `origin/codex/ready-core-pilot-2026-07-27` совпадали;
- расхождение составляло `0/0`;
- индекс был пуст.

Push должен выполняться без `--force`.

## 7. Контроль перед commit

Перед созданием commit обязательно:

1. добавить только явный allowlist настоящего документа;
2. проверить `git diff --cached --name-status` и
   `git diff --cached --stat`;
3. подтвердить ровно 122 staged-файла;
4. подтвердить отсутствие всех путей раздела 4;
5. выполнить `git diff --cached --check`, отдельно подтвердить только
   четыре сохранённых Markdown-разрыва отчётов 125, 127, 131 и 134 и код
   `0` при исключении этих четырёх неизменяемых доказательных файлов;
6. повторить `manage.py check`, контроль миграций и JavaScript-набор;
7. создать commit с сообщением
   `fix: закрыть недельные и трафиковые дефекты ready-core`;
8. выполнить обычный push без force;
9. сверить локальный и удалённый SHA.

## 8. Где проверять результат

После успешного push результат проверяется в ветке:

production остаются без изменений.
