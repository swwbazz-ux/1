# «Горный мастер» 0.1.45. Фото при восстановлении связи

## Поведение на общем планшете

При запуске без связи в шапке отображаются инициалы текущего мастера. После восстановления связи пульт получает портрет для подтверждённой открытой смены. Фотография находится только в оперативной памяти открытого экрана. Если Wi-Fi временно пропал, уже показанное фото может остаться до закрытия этого экрана. При закрытии приложения, завершении смены или смене мастера фото освобождается. Полный запуск без сети вновь показывает инициалы. В пульте и «Расстановке» используется один портрет.

Обновление удаляет фотографии, сохранявшиеся прежними выпусками, и исключает их из новых копий пульта и отчётов. Смена, парк техники, предварительная расстановка и очередь подписанных действий сохраняются на устройстве по прежним правилам.

## Обмен с системой

При действующей личной веб-сессии сервер может вернуть портрет в штатной шапке собственной смены. Для ситуации, когда остался только подписанный допуск планшета, подготовлено расширение протокола master-field/2. Ответ содержит версию личной фотографии. При изменении версии планшет запрашивает новую миниатюру, а при удалении фотографии возвращает инициалы. Ответ от уже завершённой смены отбрасывается, даже если тот же сотрудник открыл следующую. При отзыве доступа применяются обычные правила личного допуска.

Дополнительно устранена ошибка при обработке подтверждений операций в пересменке. Если подтверждение не содержит нового срока допуска, планшет сохраняет подтверждённый срок того же сотрудника и поколения. Явная отмена доступа или его истечение прекращают действие допуска. Для ранее повреждённой записи можно восстановить первоначальный срок из личной записи только после успешного подписанного ответа сервера.

Фактическая установка, контрольная сумма APK, результаты проверок и состояние рабочего сервера фиксируются в архиве выпуска.
