# Матрица приёмки без сети — водитель и машинист (30.09.2026)

Правило владельца: вся механика работает на телефоне; сервер — статист, только принимает и присылает новые данные. Приложение никогда не ждёт ответа или сверки с сервером. Любая правка полевых приложений проходит эту матрицу целиком на стенде: **сервер выключен** (порт закрыт) и **слабый сигнал** (порт принимает соединение и молчит — `scripts/blackhole.js` из пакета диагностики экскаваторщика). Действия — настоящими жестами: удержание через обработчик удержания (pointerdown → таймер → pointerup), ввод показаний с событием `input`, свайпы барабана. Проверка «из кэша» — по логу сервера, не по `transferSize`.

## A. Старт и оболочка
| # | Сценарий | Ожидание |
|---|---|---|
| A1 | Холодный старт, смена закрыта, сервер выключен | экран из кэша ≤ 2 с, замка контракта нет, техника/точки видны |
| A2 | Холодный старт, смена открыта, сервер выключен | то же, состояние смены и рейса — местное |
| A3 | Старт при слабом сигнале | экран ≤ 2 с, ни один файл не ждёт сеть; таймаут только когда кэша нет |
| A4 | Перезапуск с сетью | по логу сервера: оболочка и версионированная статика не качаются повторно |
| A5 | Обновление версии оболочки | подхватывается при сети, без блокировки работы до подхвата |

## B. Смена
| # | Сценарий | Ожидание |
|---|---|---|
| B1 | «Начать смену» без сети (настоящее удержание, показания введены) | сразу рабочий экран; событие в очереди; все кнопки смены включены; экран продолжает обновляться (busy-причин нет, `driverRefreshBusyReason`/`isDriverOperationalRefreshUnsafe` пусто/false через 5 с и после прихода фрагмента) |
| B2 | «Закрыть смену» без сети | сразу форма следующей смены с показаниями конца; экран не блокируется |
| B3 | Вторая смена без сети после B2 | открывается сразу; события ссылаются на новую местную смену |
| B4 | Перезапуск приложения без сети после B1/B2 | местная смена и очередь на месте, кнопки в правильном состоянии |
| B5 | Сервер вернулся | смены созданы/закрыты временем нажатия; все события `accepted`, ни одного `conflict`/`retry` по делу; чужая открытая смена сотрудника закрыта временем новой |

## C. Работа в местной (неподтверждённой) смене без сети
| # | Сценарий | Ожидание |
|---|---|---|
| C1 | Простой: старт, смена причины, завершение | сразу, таймер идёт, в очереди; после сервера — интервалы и суммы как нажато, соседние события не сдвинуты |
| C2 | Быстрый набор причин (звёздочки) | меняется локально, отправка при сети |
| C3 | Ручная погрузка по основному назначению → отмена → погрузка → разгрузка | сразу, круг/барабан меняются локально |
| C4 | Свободный ковш: выбор → отмена → выбор → погрузка → разгрузка (режим гаснет) | сразу; иконки и точки из кэша; отмена работает без сети |
| C5 | Смена точки разгрузки у рейса | сразу, в очереди |
| C6 | Погрузка машинистом (стандартный рейс) — разгрузка удержанием у водителя | без сети — по местным данным, если рейс уже был на телефоне |
| C7 | Путёвка («Отчёт»/«Журнал») | рейсы, простои, итоги видны сразу из событий телефона; после сервера — те же строки без дублей; отклонённые — с пометкой |
| C8 | Отклонённые сервером события (старые) | не блокируют экран и новые действия |

## D. Машинист (дополнительно к A–B)
| # | Сценарий | Ожидание |
|---|---|---|
| D1 | Погрузка самосвала, отмена погрузки | сразу, через очередь; прямые `fetch` не блокируют |
| D2 | Свободный ковш: приём, отмена, погрузка под ковш | кнопка и карточки включены в местной смене |
| D3 | Простой: старт/смена/завершение | как C1; авто-«Ожидание самосвалов» — временем события, не сервера |
| D4 | Настройки забоя | сохраняются на телефоне, уходят при сети; вкладка не выключена в местной смене |
| D5 | Закрытие → открытие следующей смены | как B2–B3, кнопка «Начать смену» доступна и после перезапуска |
| D6 | Повтор старого события после обновления | `deduplicated`, не `event_id_reused` |

## Отчёт исполнителя
Таблица «сценарий → сервер выключен → слабый сигнал → после возврата сервера → что осталось» + временная шкала по базе (время нажатия vs сервер) + лог сервера для A4. Хеш коммита. Без этого отчёта ветка в очередь выпуска не встаёт.
