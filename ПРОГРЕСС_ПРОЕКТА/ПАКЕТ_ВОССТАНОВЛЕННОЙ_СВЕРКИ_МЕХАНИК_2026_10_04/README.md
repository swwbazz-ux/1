# Пакет восстановленной проверки паспортов механик

Восстановленный разбор использует runtime-срез `swwbazz-ux/1@ecb61af55b699a7a2417abba6df4dd490f3464a9`. В `source-plan.json` зафиксированы **44 локальных вхождения, 37 уникальных путей**: commit, путь в репозитории, назначение, число байтов, Git blob SHA и SHA-256. Все 44 исходника заново получены и проверены локально. Полные исходники `source/` в публикацию доказательств не дублируются.

Утраченные при очистке workspace результаты предыдущего разбора не используются как выполненные проверки этого пакета. Здесь сохранены новые ограниченные пробы, их результаты и границы применимости. Код возврата 0 означает, что проба воспроизвела заявленное наблюдение; контрпример также может завершаться кодом 0. **Это не product PASS и не подтверждение отсутствия коллизий.**

## Подготовка для повторения

Нужны Python 3, Node и существующий checkout репозитория с указанным commit. Подготовка поддерживает Linux/macOS или WSL; прямой запуск под Windows без POSIX-защиты путей отклоняется. Полный проход bootstrap на настоящем checkout в текущей среде — **NOT_RUN**: такого checkout здесь нет. Для самого скрипта выполнены только `py_compile` и `--help`; это не подменяет bootstrap-проверку.

Сначала скопируйте опубликованный proof-пакет целиком **в отдельный каталог вне любых Git checkout**, сохраняя структуру и `source-plan.json`. Это рабочая копия для проверки: runners записывают результаты рядом с собой, поэтому не запускайте их поверх единственного архивного экземпляра доказательств.

Из корня этой отдельной копии:

```sh
python prepare_sources.py --repo /path/to/existing/repository --output "$PWD"
```

Скрипт только читает `git show <точный commit>:<путь>` и сверяет все пути, размеры и хеши до создания входных файлов. Он не делает fetch, checkout, commit, push, deployment и не меняет Git или production. При отсутствии commit подготовка прекращается. Назначения разрешены только внутри `evidence/<контур>/source/`; выход за каталог, symlink и перезапись несовпадающего файла запрещены. Уже совпадающий файл остаётся без изменений. Для безопасной работы используется отдельный каталог, не общий каталог с одновременно меняющимися файлами.

## Шесть адресных запусков

После успешной подготовки, из корня копии пакета:

```sh
node evidence/offline/probe.cjs
python evidence/offline/clock_probe.py
python evidence/shifts/probe.py
python evidence/trips/probe_late_free_bucket.py
python evidence/downtimes/probe.py
node evidence/assignments/transport_probe.cjs
```

| Контур | Что проверяет и чего не доказывает |
|---|---|
| Offline JS | Настоящие функции Driver outbox с подставными хранилищем и транспортом: ошибка записи, terminal retention, будущий wire-ответ и ограниченное наблюдение незавершённой отправки. Не браузерный IndexedDB и не native timeout. |
| Clock Python | Точная AST-функция нормализации времени с заданной фикстурой; изменение времени при `sent_live`. Не реальный сетевой замер. |
| Shifts Python | Адресные сменные функции с doubles и явно указанными данными. Не полная Django-транзакция, PostgreSQL или полевое подтверждение. |
| Trips Python | Поздний выбор свободного ковша и влияние на более новый рейс в извлечённой функции. Не полный HTTP-путь и не установленный цикл E2. |
| Downtimes Python | Временные границы и последовательности в адресных функциях простоев. Не полная конкурентная БД или универсальная норма выбора времени. |
| Assignments JS | Реальный транспорт управленческих команд в ограниченной среде. Не полный UI, серверная авторизация и не доказательство производственного победителя независимых команд. |

Точный охват и ограничения каждой пробы указаны в `evidence/<контур>/README.md` и её JSON-результате. Общие PostgreSQL-конкуренция, браузер/IndexedDB, все direct/fallback-пути, нагрузочные сценарии и физические телефоны — **NOT_RUN**. Наличие исходника, статическая проверка и успешное выполнение диагностической функции не повышают эти статусы.

Общий `SHA256SUMS` проверяет опубликованные материалы пакета; runtime-входы отдельно проверяются по `source-plan.json`. Изменение скрипта, фикстуры или источника требует нового результата с явным указанием версии. Этот пакет не является разрешением merge или deploy.
