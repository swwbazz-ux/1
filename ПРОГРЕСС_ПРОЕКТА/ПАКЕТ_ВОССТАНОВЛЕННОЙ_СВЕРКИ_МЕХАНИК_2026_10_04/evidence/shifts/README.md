# Новая проверка после восстановления, 04.10.2026 Asia/Vladivostok

Старые scratch/raw этого исследования утрачены при автоматической очистке. Этот пакет заново получает точные первичные исходники `swwbazz-ux/1@ecb61af55b699a7a2417abba6df4dd490f3464a9` и заново исполняет две диагностические проверки. Он не восстанавливает отсутствовавшие старые доказательства предположением.

Запуск: `python probe.py` из этой папки либо `python <путь>/probe.py`.

`source-manifest.json` содержит репозиторные пути и Git blob SHA. Скрипт перед выполнением сверяет все 11 файлов по формуле Git blob; `results.json` также содержит SHA256 и размер каждого источника.

- `SHIFT-OPEN-DELIVERY-ORDER`: исполняется извлечённое тело `open_driver_shift_from_device`; ORM, транзакция, получение внешних сущностей и побочные действия заменены явными in-memory doubles. Два достоверно упорядоченных открытия одного сотрудника и самосвала подаются в двух порядках доставки. Получены разные текущие смены.
- `SHIFT-R21-OWN-EARLIER-CLOSE`: исполняется реальная ранняя ветвь `_process_driver_shift_closed_by_device` для уже служебно закрытой смены. Фикстура явно предполагает достоверное более раннее собственное окончание этой же смены, то есть область R-21. Ответ `already_closed` не применяет собственное время и показания. Проверка достоверности часов, доступа и ORM находится вне области прогона.

Код возврата 0 означает успешное воспроизведение диагностических утверждений, **не исправность продукта**. Оба результата — `COUNTEREXAMPLE_REPRODUCED`. Django/PostgreSQL/HTTP, блокировки и конкурентные транзакции, полный набор побочных эффектов, установленный WebView/телефон и production не запускались: `NOT_RUN`.

Статический обзор дополнительных исходников поддерживает описанные ограничения carryover, атрибуции отчёта и различия guard диспетчера; он не добавляет runtime PASS. Полный источник presence не проверен: `SOURCE_REVIEW_NOT_COMPLETED`.
