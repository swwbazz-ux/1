# Восстановленная адресная проверка офлайна

Заново получены десять файлов из `swwbazz-ux/1@ecb61af55b699a7a2417abba6df4dd490f3464a9`. Их байты проверены по Git blob SHA и SHA-256 в `source-manifest.json`. Лишний EOF LF, добавленный локальным инструментом записи, удалён только там, где это давало точное совпадение Git blob. Код проверяемых функций не исправлялся.

Это **новые ограниченные пробы после восстановления workspace**. Они не восстанавливают и не подтверждают утраченную прошлую матрицу, PostgreSQL, CI или установленные телефоны. Код возврата 0 означает, что наблюдения совпали с диагностическими ожиданиями; он не означает исправность всей системы.

Воспроизведение (Python 3 и Node): сначала сделайте отдельную копию всего proof-пакета вне любых Git checkout, как указано в общем README. Из каталога `evidence/offline/` этой копии:

```sh
python prepare_sources.py /path/to/repository
node probe.cjs
python clock_probe.py
```

Местный `prepare_sources.py` — только совместимая обёртка общего защищённого bootstrap: готовит все входы из общего `source-plan.json`, запрещает symlink/выход из каталога и перезапись несовпадающих файлов. Он извлекает точные версии через `git show`; изменений Git или runtime в репозитории не делает. Требуются Linux/macOS или WSL. Папка `source/` — воспроизводимый локальный ввод, её не требуется дублировать в документальной ветке. Полный bootstrap с настоящим checkout здесь **NOT_RUN**; у скриптов проверены только синтаксис и справка.

| Проба | Фактическая область и результат |
|---|---|
| Quota | Настоящий Driver outbox, localStorage double: enqueue отклонён, `onState` не вызван. Положительная проверка узкой функции. |
| Terminal retention | Настоящий outbox при initialize удалил запись conflict старше 25 часов; архив/identity-квитанция в этом модуле не записаны. Не утверждается удаление серверного receipt. |
| Будущий literal no_effect | Синтетический будущий ответ оставляет Driver-событие pending/retry. Текущий сервер не объявлен источником такого wire-ответа. |
| Незавершающийся send | Promise остаётся pending в ограниченном 25-мс наблюдении, повторный flush возвращает тот же promise, факт сохранён. Реальный HTTP timeout/native lifecycle не измерены. |
| sent_live | Выполнена точная AST-функция normalize с четырьмя стандартными вспомогательными зависимостями и явно заданной фикстурой. Исходные 10:00 при receipt 10:10 становятся операционными 10:10 только из-за sent_live; fingerprint прежний. Это не доказательство, что реальная сеть задерживалась на десять минут. |

`probe-result.json` и `clock-result.json` содержат результаты текущего выполнения. Полные браузерные, IndexedDB, PostgreSQL, нагрузочные и установленные Android-сценарии — **NOT_RUN**.
