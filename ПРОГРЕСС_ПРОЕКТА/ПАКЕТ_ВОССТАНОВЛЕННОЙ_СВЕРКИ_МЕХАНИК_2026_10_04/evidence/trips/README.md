Это новый ограниченный прогон на заново полученных исходниках. Прежние raw-файлы после очистки workspace недоступны. Старые 6480 перестановок P28 не восстановлены и не заявляются результатом этого пакета.

`sources.json` содержит 6 точных Git blob SHA, SHA256 и размеры. Каждый сохранённый исходник проверен стандартным Git-хешем `SHA1("blob " + byte_length + NUL + bytes)`; совпадение 6/6. Раннер дополнительно проверяет SHA исходника перед извлечением функции.

Запуск из любой рабочей директории:

```bash
python /полный/путь/evidence/trips/probe_late_free_bucket.py
```

Функция `_release_open_trips_unknown_to_worker` извлекается через AST без переписывания тела. `Trip.objects`, `save`, журналирование и закрытие free-bucket заменены явно описанными doubles. Появление нового рейса Y — вставка fixture, не вызов настоящего обработчика погрузки. DB, Django, внешняя сеть и production не используются.
