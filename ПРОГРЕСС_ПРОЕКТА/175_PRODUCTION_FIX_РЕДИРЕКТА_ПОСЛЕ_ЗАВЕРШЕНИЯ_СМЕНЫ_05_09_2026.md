# Production-исправление редиректа после завершения смены — 05.09.2026

## Инцидент

При завершении диспетчерской смены Сергеевым Василием Владимировичем через
режим администратора «управление от имени сотрудника» сервер вернул
`Server Error (500)`. Nginx зафиксировал ошибку на
`POST /dispatcher/shift/toggle/` в `10:44:43 UTC`.

Сама операция завершилась успешно до ошибки ответа: смена №165 получила
`closed_at=2026-09-05 10:44:43 UTC`, `closed_by_id=394`, открытых смен у
сотрудника после операции нет. Аудит действия администратора также сохранён.

## Причина и исправление

После успешного ответа `302` middleware режима управления должен был оставить
параметр `observe` в адресе перехода. Метод `_keep_token_on_redirect` был
объявлен статическим, но обращался к `self.exit_paths`, из-за чего возникал
`NameError: name 'self' is not defined` уже после сохранения смены.

Метод переведён в `classmethod`, обращение заменено на `cls.exit_paths`.
Добавлен регрессионный тест, который проверяет внутренний редирект и сохранение
пропуска без серверной ошибки.
