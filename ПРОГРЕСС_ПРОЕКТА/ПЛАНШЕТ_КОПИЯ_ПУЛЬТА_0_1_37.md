# Планшет 0.1.37. Предварительная расстановка

Основа — подтверждённый APK 0.1.35 (267f8b3dc37618be938a85890dabc83130845605), штатный адрес запуска /mining-master/tablet/. В существующей шапке планшета «Отчёты» заменены на «Расстановка». Для копии приложение берёт реально открытый пульт мастера, карточки, стили и размеры плиток. Общее хранилище черновика принадлежит этому планшету. Первый черновик начинается с действующей расстановки. Другой мастер после входа в собственную смену может продолжить его.

Вкладка поддерживает назначение двумя касаниями и перетаскиванием. Нижняя панель содержит поиск самосвала, «В группу» и «Активировать расстановку». «В группу» открывает предпросмотр текста, далее доступна системная передача или копирование. Формат групповой публикации и целевая группа MAX ещё не согласованы. Обычный вход и пульт работают как в 0.1.35. При сетевой ошибке загрузки самого пульта используется ранее сохранённое поле с его оформлением. Подготовка черновика доступна без сети после первой загрузки и подтверждения собственной смены. Новый сотрудник проходит штатный вход.

Активация требует явного подтверждения. Если хватает одной штатной операции, она передаётся через уже работающий интерфейс сервера с проверкой версии и авторизации. Несколько операций нельзя применить по частям: запрос сохраняется на этом планшете. На текущем рабочем сервере общий приёмник атомарного применения вернул HTTP 404. Составные изменения не появятся у диспетчера до подключения приёмника. Для получателя есть отдельный локальный исходник и проверки в C:/codex-tmp/tablet-field-sync-20261102. При работе без связи экран сохранённого пульта может отобразить явно активированный локальный план с отметкой ожидания. Актуальную связь и смену проверяют перед передачей.

В браузере на базе подлинного пульта e781 проверены обычный личный вход, точное совпадение исходного поля с 0.1.35, девять видимых карточек и следующий ряд на прокрутке, сохранение и изоляция правок, штатные жесты, холодное восстановление снимка без сети и применение одного назначения в тестовой базе. Исходные CSS и обработчики существующего пульта сверены с архивом 0.1.35. Состояние устройства и SHA-256 установленного файла записаны в installed.json. Публикаций на рабочий сервер и в GitHub не выполнялось.
