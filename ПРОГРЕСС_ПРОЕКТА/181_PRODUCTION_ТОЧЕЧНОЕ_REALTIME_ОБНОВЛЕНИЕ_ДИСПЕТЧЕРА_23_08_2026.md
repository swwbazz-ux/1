# Точечное realtime-обновление Горного диспетчера

Дата: 23.08.2026.

## Итог

На production опубликован commit
`9825aa507c9bef6d0c3697544fe180452024de63`. Исправлена ложная замена всех
карточек рабочего поля при получении одного релевантного realtime-события.

Причина: браузер сравнивал новый серверный HTML с уже изменённым JavaScript
живым DOM. Технические классы, атрибуты drag-and-drop и размеры ошибочно
воспринимались как изменение производственных данных.

Теперь каждая карточка Экскаватора, комплекса и Самосвала получает внутренний
отпечаток исходного серверного состояния. При обычном событии заменяются только
карточки, чей новый серверный отпечаток действительно отличается. Технические
изменения живого интерфейса не вызывают замену. Полная замена поля сохранена как
защитный fallback при неполном fragment-контракте, обрыве журнала событий или
слишком большом отставании версии.

Частота проверки realtime не менялась: один узкий запрос раз в пять секунд.
Полная HTML-страница при производственных событиях не загружается.
