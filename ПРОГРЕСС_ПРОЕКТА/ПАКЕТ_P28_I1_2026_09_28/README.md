# P28-I1 — исполняемое ядро выбора направления

Пакет выполнен на документационной основе `1226645bfb9d177e822b1de7526ea93a54a8da36`; зафиксированная для сопоставления release-основа — `f2248cb79c737e98b580e784abea394335a2700b`.

Это изолированный прототип утверждённых P28-В1…В3. Он не импортирует Django, не читает и не меняет БД, не подключён к handlers, очередям, экрану или native-озвучке.

- `route_core.py` — неизменяемые маршрутные события, append-only ledger, причинная проекция и отдельная проверка жизненного цикла рейса;
- `test_route_core.py` — 22 теста утверждённых исходов и защитных границ;
- `run_tests.py` — UTF-8 runner с трассами и явным кодом завершения;
- `run.ps1` — проверка точной документационной основы и запуск без Django;
- `CONVERGENCE.md` — обоснование причинного алгоритма и границы доказательства;
- `raw-run-utf8.log` — сохранённый вывод финального запуска;
- `SHA256SUMS.txt` — SHA-256 опубликованных LF-байтов;
- `SHA256SUMS.windows-local.txt` — SHA-256 локальных байтов Windows перед commit.

## Нормализованный вход

`RouteEvent` хранит:

- неизменяемые `event_id` и SHA-256 fingerprint бизнес-содержания;
- `trip_id`, тип, автора и роль;
- выбранную точку;
- ID реально наблюдённых причинных предков;
- отдельно время действия и время получения;
- идентичность исходной погрузки.

`TripRouteContext` отдельно хранит исходную точку и автора погрузки. `LifecycleEvidence` отдельно сообщает доказанную отмену, разгрузку, замещение или технический `UNCONTROLLED`.

## Граница доверия

Ядро считает вход уже проверенным. Будущий адаптер обязан отдельно:

1. аутентифицировать автора, роль и полномочие на конкретный рейс;
2. проверить существование рейса/точки и неизменяемость ID/fingerprint;
3. доказать, что каждый `observed_ancestor_id` действительно был показан создавшему событие приложению, а не принят как произвольная клиентская строка;
4. транзакционно сохранить ledger и подтверждённые свидетельства жизненного цикла;
5. передать честный признак полноты legacy-истории;
6. отделить серверную проекцию от доставки, DOM, обновления экрана и native-озвучки;
7. дедуплицировать реальное уведомление по `notification_key` и хранить подтверждение воспроизведения, если это будет отдельно утверждено.

Сам прототип не доказывает ни один из этих пунктов.

## Трассы до результата запуска

| Вход | Ожидаемый результат |
|---|---|
| Независимые `D:P2` и `O:P3`, оба порядка | `P2`, оба события сохранены |
| `D:P2 → O:P3`, O доставлен раньше D | До D — `causality_incomplete`; после D — `P3` |
| `O:P1 → D:P2` | `P2`; исходная погрузка не меняется |
| O причинно позже D при часах O −3 минуты | O; часы не заменяют причинность |
| Независимый D и цепочка `O1 → O2` | D по P28-В3; O1 остаётся в истории |
| Четыре события во всех 24 порядках доставки | Одинаковая конечная проекция |
| Две цепочки с актуальными O1/O2 | `policy_unresolved`, без попарного цикла |
| Повтор/потеря ответа/restart из snapshot | Одна запись и та же проекция |
| Один ID с другим payload; плохой fingerprint | `integrity_conflict`, оригинал не заменён |
| Отсутствующий предок; цикл; неполная legacy-история | Честное состояние неполноты, без победителя |
| Ссылка на другой рейс | Межрейсовая причинность не создаётся |
| Два независимых автора одной роли | `policy_unresolved` |
| Сменщик того же экскаватора | Автор погрузки и автор маршрута различимы |
| Технический `UNCONTROLLED` | Не считается разгрузкой; маршрут остаётся оперативным |
| CANCELLED / разгружен / доказанно замещён | История и выбранное событие сохранены, показ/уведомление запрещены |
| Неизвестная история замещения | Консервативно запрещён оперативный показ |
| Legacy actual без происхождения | Новое событие и уведомление не выдумываются |

Подробный машинный вывод находится в `raw-run-utf8.log`.

## Честные ограничения

- SQLite и PostgreSQL не запускались и к этому pure-Python модулю не подключены.
- Не проверены реальная доставка, многопроцессная/транзакционная запись, DOM, установленное приложение, Xiaomi/WebView и native audio.
- Перебор 24 перестановок проверяет одну фиксированную разветвлённую историю, но не доказывает все возможные графы.
- Для независимых актуальных событий одной роли и иных неутверждённых сочетаний ядро возвращает `policy_unresolved`; никакая новая производственная политика не выбрана.
- Пакет не исправляет установленное приложение и не меняет существующие обработчики.
