## 9. Новый дефект QA-REG-P1-DRIVER-LOGOUT-HOLD-001

Название: **Удержание кнопки выхода Водителя падает с JavaScript-ошибкой**.

Статус: **ВОСПРОИЗВЕДЕНО / P1**.

### 9.1. Живое воспроизведение

На `390×844` выполнено настоящее удержание кнопки `Выйти`.

Получено:

```text
ReferenceError: holdMs is not defined
at drawLogoutHold
URL после удержания:
http://driver.localhost:8000/driver/?tab=shift
```

Переход на экран входа не произошёл.

Обычный короткий click может успеть отменить animation frame и не показать
ошибку. Поэтому дефект пропускается при smoke-проверке без настоящего
удержания.

### 9.2. Причина

В `templates/users/driver_shift.html`:

- `drawLogoutHold()` использует `holdMs`;
- в области обработчика logout эта переменная не объявлена;
- одноимённые переменные существуют только в других вложенных функциях и не
  доступны этому обработчику.

Текущая проблемная строка находится около:

```text
templates/users/driver_shift.html:3922
```

### 9.3. Требуется

1. Ввести отдельную локальную константу длительности logout-hold.
2. Не использовать переменную из чужой вложенной области.
3. Подтвердить:
   - удержание нужное время выполняет ровно один переход на `/logout/`;
   - преждевременный отпуск сбрасывает прогресс;
   - повторное удержание работает;
   - в read-only старой PWA logout остаётся доступен;
   - ошибок консоли нет.
4. Добавить исполняемую JavaScript-регрессию настоящего production-handler.
5. Повысить shell/service-worker версию PWA Водителя.
6. Выполнить Browser QA `1280×720` и `390×844` с настоящим удержанием.
