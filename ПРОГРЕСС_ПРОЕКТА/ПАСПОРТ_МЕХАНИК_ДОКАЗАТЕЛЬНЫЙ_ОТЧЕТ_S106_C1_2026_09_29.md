## 1. Вывод

Простое объединение списков кодов **недостаточно**. Release умеет целиком
восстановить отказанную ручную погрузку свободного ковша и её цепочку, но не
поднимает ребёнка после удаления принятого родителя и подменяет честное время
ребёнка машиниста временем получения. PR №106 поднимает независимого ребёнка и
сохраняет его собственное время, но теряет релизный корень
`driver.trip.loaded/free_bucket_not_available`: клиент отправляет только
зависимый complete, а две релизные серверные функции в PR отсутствуют.

Целевой проект: единая серверная функция возвращает отдельно допуск, причину,
политику времени и политику зависимости; клиент повторяет исходный конверт,
сервер заново разрешает **собственные** ссылки и проводит предметные проверки.
При интеграции должен быть сохранён весь релизный путь восстановления/self-
accept свободного ковша. Это рекомендация для следующего ограниченного патча,
а не реализованный или уже утверждённый diff.

## 4. Два технических различия для Астры

### 4.1. Время зависимого события машиниста

Минимальная трасса:

1. parent имеет собственный `device_clock_ahead`;
2. child создан позже на телефоне уже с честным `occurred_at`;
3. release допускает child из-за skewed parent, но выставляет
   `clock_adjusted=True` и применяет `child.received_at`;
4. PR допускает child, но сохраняет `child.occurred_at`.

Проверка release красная ровно на 30 секунд: применено время получения вместо
времени child. PR проходит ту же проверку. Рекомендация: **сохранить поведение
PR** — недостоверность родителя влияет на готовность/диагностику зависимости,
но не доказывает недостоверность часов ребёнка. `received_at` разрешён только
для события, чей собственный skew доказан. Это следует из утверждённых
ГП-0.2.6 и `CR-TIME-001`; нового производственного выбора не вводит.

### 4.2. Собственные ссылки при отказанном или чужом предке

Минимальная трасса:

1. parent остаётся terminal либо принадлежит другому owner/device;
2. child после restart сохраняет прежние `event_id`, payload, sequence,
   `depends_on` и время;
3. release оставляет child terminal;
4. PR отправляет child и его handler разрешает собственный `local_trip_id`;
5. проверки подмены device и wrong event type остаются закрытыми.

Рекомендация: зависимость — причинная/транспортная подсказка, не источник
полномочия и не поставщик object ID. Self-contained child обрабатывается по
собственным ссылкам. Если их недостаточно, сервер хранит `retry` предметного
типа; он не заимствует данные чужого parent и не отвечает ложным `no_effect`.
Это согласуется с утверждённым ГП-0, но конкретные `CR-OFF-001/002/004`
по-прежнему кандидаты; зелёный probe не повышает их статус.
