- релевантное событие: ровно один узкий Driver fragment;
- нерелевантное событие: fragment `0`;
- введённое, но не отправленное значение топлива сохранилось;
- console errors/warnings: `0`;
- offline reload PWA прошёл.

Пятьдесят последовательных realtime GET:

- `50/50 HTTP 200`;
- p50 `11,7 мс`;

проверяется каждые 5 секунд, а сервер загружает узкий fragment только при
релевантном изменении.
