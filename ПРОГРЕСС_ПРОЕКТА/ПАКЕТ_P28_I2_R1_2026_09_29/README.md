Пакет проверяет отдельный неподключённый Django-адаптер свидетельств маршрута. Он не подключает адаптер к обработчикам или экранам и не изменяет БД приложения.

## Запуск

Из корня `docs/mechanics-passport`:

```powershell
$python = 'C:\Users\swwba\Desktop\Проект учетная система\ПОЕКТ\СИСТЕМА_MVP\.venv\Scripts\python.exe'
& $python '.\ПРОГРЕСС_ПРОЕКТА\ПАКЕТ_P28_I2_R1_2026_09_29\run_isolated_r1.py' `
  --candidate-root 'C:\codex-tmp\p28-i2-r1-route-evidence-adapter-20260929'
```

Runner отказывается работать, если:

- HEAD или release-base не совпадают с зафиксированными;
- есть staged, unstaged или untracked изменения;
- изменён blob ядра R1;
- изменены исходные три probe;
- в checkout лежит `.env`;
- после настройки соединение не является временной SQLite `:memory:`.

В журнал попадают stdout, stderr и итоговый exit code. Для проверки dirty-gate предусмотрен `--preflight-only`; пример и фактический журнал опубликованы в доказательствах R1.
