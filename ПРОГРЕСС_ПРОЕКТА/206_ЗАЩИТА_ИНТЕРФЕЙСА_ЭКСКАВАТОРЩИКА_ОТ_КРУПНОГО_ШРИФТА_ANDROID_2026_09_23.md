# Защита интерфейса Экскаваторщика от крупного шрифта Android — 23.09.2026

## Полевое проявление

На фотографиях production APK `0.1.28 (44)` системный крупный шрифт Android
масштабирует текст внутри WebView поверх уже рассчитанного мобильного интерфейса.
Из-за этого нарушаются все основные экраны, а не один отдельный блок:

- заголовок входа переносится по одной букве и выталкивает форму;
- шапка, карточки самосвалов и нижняя навигация обрезают подписи;
- экраны «Смена», «Забой» и «Простой» теряют часть текста и доступной площади;
- фиксированные рабочие карточки начинают перекрывать соседние элементы.

CSS `text-size-adjust` уже присутствовал в контуре Экскаваторщика, но не
нейтрализовал системный масштаб нативного Android WebView. Поэтому точечное
уменьшение десятков CSS-размеров не является надёжным исправлением.

## Принятое решение

Только нативные профили Экскаваторщика задают `WebSettings.setTextZoom(100)`.
Настройка повторно применяется при создании и возобновлении Activity. Она не
меняет системный размер шрифта телефона, другие приложения и профили Водителя.

Профильное значение проходит через `app.properties` и `BuildConfig`:

- Excavator direct: `0.1.29 (46)`;
- Excavator RuStore QA: `0.1.29-rc (47)`;
- Excavator RuStore public: `0.1.29 (48)`;
- side-by-side Excavator QA сохраняет пакет
  `ru.copperresources.excavator.qa`, версию `1.0.9-qa (10)` и получает то же
  ограничение масштаба.

Водительские профили не содержат `webViewTextZoomPercent`, для них значение
остаётся `0` и нативное поведение не меняется.

## Связанные версии оболочки

Для уже подготовленного shell Экскаваторщика `v252` все ссылки на его CSS/JS и
серверный список core assets приведены к одному cache-key `v252`. Это исключает
смешение нового HTML со старыми кешированными ресурсами и не меняет сам дизайн.

## Состояние публикации

Исправление зафиксировано только в локальной hotfix-ветке вместе с исправлением
неверного времени телефона. Push, `VERIFY`, deploy и публикация APK для этого
изменения не выполнялись. Production manifest продолжает отдавать
Экскаваторщика `0.1.28 (44)`.
