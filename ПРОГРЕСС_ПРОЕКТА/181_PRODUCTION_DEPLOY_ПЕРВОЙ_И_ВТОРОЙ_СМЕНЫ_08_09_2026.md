# Production deploy первой и второй смены по расстановке — 08.09.2026

## Результат

На `driverform.ru` опубликован release
`443c9d8f42caa055cdddf39b40e7b88095cc0e1b` из ветки
`codex/shift-assignment-semantics-prod-2026-09-08`.

Рабочую смену Водителя и Экскаваторщика теперь определяет принятое назначение

## Live-aware композиция

Исходная ветка изменения расходилась с production. Фактический серверный маркер
был `fc5f96a70f07f562007e079da50e47364160edb9` и уже содержал новые изменения
диспетчера и горного мастера. Release собран поверх этой линии, поэтому они не
перезаписаны. Шесть первоначально отличавшихся live-файлов проверены отдельно:
содержимое совпадало с базой, различались только переводы строк.

Миграция подписей приложения `assignments` перенумерована в `0013` и продолжает
production-цепочку после `0012_haul_assignment_handoff`. Остальные state-only
миграции: `reports.0012`, `rotations.0009`, `shifts.0016`.
