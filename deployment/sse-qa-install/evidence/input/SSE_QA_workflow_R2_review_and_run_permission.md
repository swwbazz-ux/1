## Независимая проверка

Архив, manifest из 26 файлов и внешний список контрольных сумм совпали. R2 наложен на ранее проверенный R1/R4; package self-check подтвердил 76 файлов.

В окружении рецензента прошли **58/58 доступных тестов**, включая все **7/7 новых адресных проверок** и POSIX-тест. Два прежних теста, импортирующих Django, здесь не повторялись из-за отсутствия Django. Авторские 59 PASS / 1 Windows SKIP не выдаются за независимо повторённый полный набор. В самом workflow теперь предусмотрен отдельный test-venv с установкой зависимостей и запретом skip.

| Замечание R1 | Результат R2 |
| --- | --- |
| Неподходящий формат wheelhouse manifest | Закрыто: basename без `./` принимается настоящим валидатором установщика. |
| Неустановленные зависимости тестов | Закрыто: отдельный Python 3.12 venv, установка из wheelhouse, запуск тестов его интерпретатором. |
| nginx мог оставаться остановленным | Закрыто: явный start, проверка активности и запись состояния до цикла. |
| Смешивание журналов normal/fault/cancel | Закрыто: сохранённый InvocationID каждой попытки используется при всех чтениях её journal. |
| SHA256SUMS хэшировал сам себя | Закрыто: manifest и временный файл исключены, суммы повторно проверяются. |
| Raw log выводился до проверки секретов | Закрыто: предварительный вывод убран, scanner тихий, маски зарегистрированы, публикация зависит от успешной sanitization. |

Дополнительные безопасные проверки подтвердили разделение четырёх искусственных journal histories, ожидание InvocationID, повторное формирование manifest и отказ на искусственных секретах без вывода их значений. Настоящие службы и workflow не запускались.

Особенность patch: прямое применение к байтам Windows-архива R1 упирается в CRLF/LF у manifest и одного лога. После нормализации этих двух исходных текстовых файлов patch применяется; все 16 файлов совпадают с overlay по содержимому с учётом окончаний строк. Полный source overlay R2 и его manifest проверены отдельно. Это не новый функциональный блокер; при подготовке commit следует сохранить проверенное содержимое и штатно пересобрать manifest для фактических байтов checkout.

**Фактический Linux/systemd/PostgreSQL/Redis/nginx-цикл всё ещё `NOT_RUN`.** Принятые исправления R4 не открываются заново. Этот вывод не подтверждает нагрузочную ёмкость существующего сервера и не разрешает production-пилот.
