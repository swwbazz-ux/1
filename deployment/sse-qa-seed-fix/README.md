# Исправление seed для SSE QA C2

Этот пакет предназначен только для защищённого режима
`repair_sse_qa_seed` существующего изолированного SSE QA.

Операция:

- выполняется только при выключенном QA и неактивных QA-службах;
- принимает только закреплённый набор файлов без пользовательских путей,
  команд или SQL;
- сохраняет существующую БД, доступы, HTTPS и старую породу вместе с
  историческими ссылками;
- создаёт или подтверждает каноническую породу `Скальная порода` с
  плотностью `2.7100` и коэффициентом разрыхления `1.5100`;
- переключает только текущую постановку синтетического экскаватора
  `SSE-QA-EXC-01`;
- заменяет только две закреплённые source-копии seed-команды и её теста;
- записывает в ownership метку `C2 + seed-fix` и точные SHA-256;
- при ошибке восстанавливает исходные файлы, ownership и связь постановки.

Повторный запуск обязан завершиться как `already_applied` без новых записей.
Production-приложение, production-БД, nginx, сертификат и базовый C2 runtime
этой операцией не изменяются.
