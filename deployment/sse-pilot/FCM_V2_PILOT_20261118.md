# Ограниченный пилот срочного FCM18.11.2026

Разрешён пользователем: проверить новый режим на№99/ТЕСТ-1, без изменения CAT-9/рабочих смен; затем восстановить устройство.

Production-код, БД, nginx, systemd, receiver и общая рассылка не меняются. apply_data не применяется: этот mode перезапускает общий сервис. Проверка отправителя выполняется отдельным режимом существующего GitHub Actions workflow, с прежними environment=production, owner-only, exact SHA/confirmation. Сам workflow изменён только в отдельной пилотной ветке; общий release-job пропускается для этого режима. Ключ FCM остаётся в штатном GitHub Secret и не копируется на ноутбук.

Получатель ограничен SHA-256 токена проверенного USB-пакета ru.copperresources.excavator. Токен извлечён локально из регистрации основного процесса; открытым в файлах/Git/Actions inputs не сохраняется. Конверт AES-256-GCM с RSA-OAEP SHA-256 ключом предназначен действующему сервисному аккаунту Firebase. Публичные сертификаты взяты у Google; секретный ключ остаётся внутри production environment. Оба режима отправляют одинаковые data kind/version/probe_id, без рабочих данных и действий со сменой. Новый режим добавляет generic fallback-уведомление. Доставка любого другого токена/проекта запрещена. Пилотный отправитель прекращает работать после17.11.2026 22:30UTC (18.11 02:30Самара).

Сначала validate_only: FCM проверяет формат, сообщение не доставляется. Только после успешной проверки — временный SDK26.1.0-eap01 и callback onNotificationReceived на телефоне; сравнение по3 legacy high-priority и3 urgent RemoteNotification. Одинаковые Doze/сеть/паузы/данные. Водитель на время опыта остановлен без закрытия смены, потом запущен обратно. Исходный публичный APK0.1.30(47) сохранён для возврата через adb install -r.

Измерения: sentTime/callback/начало сверки, тип callback (исключить подмену v2 legacy-fallback), фактическое отображение/звук, число запросов, UID-трафик приложения и ограничения учёта GMS, CPU/wakelock при доступности. При USB нельзя объявлять доказанным отсутствие роста фактического разряда; размер нового payload тоже учитывать, а не заменять подсчётом запросов.

Google SDK скачан с https://dl.google.com/firebase/sdk/android/FirebaseMessaging_26.1.0-eap01.zip . FCM discovery содержит AndroidConfigV2/AndroidRemoteNotification. Это не доказывает доступность режима для данного проекта/устройства, поэтому требуется validate_only и проверка настоящего callback.

Локально7 тестов отправителя пройдены: криптографическая привязка получателя, запрет другого проекта/получателя, защита конверта, validate-only без доставки, одинаковые данные, запрет неизвестного режима и обязательное подтверждение. Пилот завершён: реальные сообщения приняты новым callback, преимущество в задержке не обнаружено. Подробности и восстановление — [итоговый отчёт](FCM_V2_RESULT_20261118.md). Временный mode/job отправителя удалён из разрешённой release-ветки, workflow возвращён к исходному.
