## Причина и исправление

Удаление приложения из недавних останавливало рабочую службу, но сохраняло старый курсор обработки. При повторном открытии накопленные события попадали в общий голосовой арбитр и звучали как новые.

Теперь onTaskRemoved сохраняет долговечный маркер тихого восстановления. Первый успешный authenticated native state response после запуска устанавливает границу серверной версии, привязанную к контексту сотрудника/техники и эпохе журнала. До этого WebView откладывает озвучку назначений. Затем native и WebView через общий арбитр отмечают снятия и назначения до границы обработанными без уведомления и голоса. Поздний повтор старых событий остаётся тихим, включая пересоздание процесса. Операции после границы и погрузки не заглушаются. Граница — первый достоверный снимок при открытии, без зависимости от часов телефона. При отсутствии сети маркер сохраняется до успешной сверки, интерфейс продолжает работать по прежним правилам.

Затронуты AssignmentVoiceResumeGate.java, ConnectivityForegroundService.java, OperationalVoiceAnnouncer.java, NativeSoundPlugin.java. Версия события передаётся общему арбитру и из native, и из WebView. Подняты версии двух sideload-профилей и зарезервированы следующие versionCode RuStore для сохранения порядка обновления; store APK не собирались/не публиковались. Автозапуск при загрузке ОС не добавлялся.
