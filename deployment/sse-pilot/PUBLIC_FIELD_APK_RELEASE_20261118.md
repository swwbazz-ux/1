## Как сотруднику обновиться

Если штатная плашка версии доступна — нажать её и подтвердить обновление. Для случая мигающей кнопки: открыть прямую ссылку в браузере, скачать APK, открыть файл и выбрать «Обновить» поверх официального приложения. Если Android запросит разрешение на установку из этого источника — выдать его браузеру. После установки открыть приложение. Штатное обновление того же package с той же подписью сохраняет данные; смену закрывать не требуется. Удаление приложения не является шагом этой инструкции.

Эти утверждения относятся к официальному native APK. Если фактически использовался PWA/WebAPK, перенос данных браузера в новый WebView нельзя обещать без отдельной проверки.
