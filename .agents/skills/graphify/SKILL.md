name: graphify
description: Поиск вызовов и зависимостей между обработчиками Copper Resources в локальной рабочей копии. Использовать для оценки последствий изменения общей функции, смены, рейса, отчёта или пульта.
---

Выберите рабочую копию по задаче. Уточните её путь и ветку через Git, если открыта общая папка с несколькими копиями. Скрипт [project_map.py](scripts/project_map.py) запускается обычным Python на Windows и сам находит изолированный Graphify CLI. Передавайте скрипту `--repo <путь к выбранному Git-репозиторию>` и команду:

- `update` проверяет состояние локального кода, строит карту при изменениях и выводит путь к HTML.
- `explain <точное_имя>` показывает соседей функции. Если имя неизвестно, сначала найдите его через `rg -n`.
- `path <имя1> <имя2>` показывает путь в графе. Для обзора нескольких узлов доступен `query "вопрос"`.

Каждый запрос проверяет HEAD и содержимое исходников Python и JavaScript/TypeScript в backend, включая новые файлы, видимые Git. Входные файлы берутся с диска. Список исключений задан в скрипте. Для файлов в выдаче используйте пути относительно `СИСТЕМА_MVP/backend` выбранной копии.

Сверяйте вызов и направление в коде. При пропущенной связи ищите имя и все промежуточные импорты, регистрацию маршрута, строковое имя события или обработчика. Пример и правила обновления приведены в разделе Graphify файла AGENTS.md.

На новом компьютере с Windows, Git и Python 3.12 установите проверенную версию CLI один раз для всех рабочих копий пользователя:

```powershell
$graphifyEnv = Join-Path $env:LOCALAPPDATA 'CopperResources/Graphify/venv'
python -m venv $graphifyEnv
& "$graphifyEnv/Scripts/python.exe" -m pip install graphifyy==0.9.121
```
