## 2. Три независимых статуса

| Статус | Значения | Чем подтверждается |
|---|---|---|
| Требование | предложено / утверждено / заменено | решение владельца или документ с датой |
| Реализация | нет / частично / есть | код, `файл:строка` |
| Проверка | не выполнена / выполнена на версии / расхождение | прогон, стенд, устройство; версия обязательна |

Исторический документ не становится действующим по дате. Наличие файла или
ссылки `файл:строка` **не** утверждает бизнес-правило; утверждает только
владелец. Код не выдаётся за решение владельца, «тест существует» — за «тест
проходит».
