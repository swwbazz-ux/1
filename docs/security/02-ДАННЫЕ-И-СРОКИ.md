## 2. Что фактически задано

Из 17 наборов срок задан только у четырёх величин, и ни одна не является
политикой хранения:

1. кэш портала — TTL 300 с (`config/settings.py:269`);
2. cookie личной сессии — год (`:170-172`; `users/session_device.py:14-27`);
3. терминальные записи клиентской очереди — 24 ч (`static/js/driver-offline-outbox-v2.js:654`, `:745`);
4. билет планшета `master-field/1` — 7 суток (`assignments/field_sync.py:48`, `:216`).

Поиск `retention|purge|cleanup_old|delete_old|older_than|auto_clean` по backend
даёт 0 совпадений; команды очистки нет. Выгрузки XLSX не сохраняются на сервере
(формируются в ответ), поэтому «очистка выгрузок» пока неприменима — но и журнала
выгрузок нет.

Итог: **SEC-06 — реализация «нет»**; это подтверждает `security/07`.
