# 07. Реестр требований SEC-01…40

- Раздел: `docs/security/`, документ 7 из 9. Дата: 2026-11-12.
- Источник требований: `Copper_Security_Baseline_v0.1.txt` (12.11.2026), рабочая
  выписка — `state/security/SEC-BASELINE.md`. **Все 40 требований — «предложено»**;
  ни одно не утверждено владельцем. Это проект, не аудит.
- Реализация: чтение кода HEAD `4aa50c7f` (`T-018-architect-1.md` §3,
  `T-018-backend-1.md` §1–2, `T-018-data-2.md` §2, `T-018-android-1.md` §2).

  браузер, APK, устройство и production не запускались; «доказательство» ниже —
  `файл:строка` (уровень L0), а не результат прогона.
- Статусы реализации: `нет` / `частично` / `есть` / `не применимо`
  (с обоснованием). «Не проверено» относится к колонке «Проверка», а не к
  реализации; в реализации такого значения нет.
