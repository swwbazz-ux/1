## 0. Как читать

| Статус | Значения | Что означает |
|---|---|---|
| Требование | утверждено / предложено / нет | есть ли датированное решение владельца |
| Реализация | есть / частично / нет | факт кода HEAD, `файл:строка` |
| Проверка | нет / чтение / браузер / расхождение | что реально выполнялось |

`файл:строка` — реализация, а не право. «Чтение» — код прочитан, экран не
открывался. В этом документе браузер, устройство, планшет и APK не запускались
ни разу: все проверки уровня «чтение».

подтверждать конкретный блок по коду, а не по названию экрана.

## 6. Сценарии (сжато)

1. **Водитель.** Начало смены — удержание 1 с; онлайн нужна расстановка, офлайн —
   только при уже назначенном самосвале (`users/views.py:5582-5609`;
   `driver-local-shift-v1.js:295-296`). Принятие назначения — «ПРИНЯТЬ» = перейти
   сейчас (решение 233). Разгрузка — удержание кольца (в коде 500 мс, подпись в
   шаблоне ещё говорит «1 секунду» — внутреннее расхождение;
   `driver-shift-v1.js:2866-2871`, `driver_shift.html:101`); точка меняется до
   закрытия рейса. Закрытие смены — удержание 1 с
   (`driver-shift-v1.js:696-700`), без сети уходит в очередь.
2. **Экскаваторщик.** Вкладки «Работа/Смена/Забой/Простой» на общем каркасе
   (`data-eo-active-tab="trucks"`, `:41`); баннер очереди событий (`:92-95`).
   Настройки забоя — только при открытой смене. Погрузка — на вкладке «Работа»:
   обычное нажатие по самосвалу; если самосвал закреплён за другим
   экскаватором, нужна заявка водителя «Под свободный ковш» и приём машиниста,
   иначе сервер отвечает `409 free_bucket_acceptance_required`
   (`trips/views.py:4437-4442`). Повторная погрузка гружёного не создаёт второй
   рейс только при выключенном `EXCAVATOR_MANUAL_LOADING_ENABLED`
   (`config/settings.py:437`, Q-33).
3. **Горный мастер.** Расстановка требует своей смены, иначе 400
   (`assignments/views.py:778-888`). Планшет: запись — только при своей смене
   (`trips/tablet_control.py:52-66`); служебное закрытие чужой смены технически
   возможно (R-3, Q-09).
4. **Диспетчер.** Перетаскивание плиток, карточка техники, назначения, ручной
   рейс, служебное закрытие смены, realtime-сверка доски. Запись требует
   **любой** открытой смены диспетчера (`trips/dispatcher_guards.py:100-150`).
5. **Делопроизводитель.** «Начать работу» → режим «Следующий заезд» →
   утверждённый состав → «Рассчитать размещение» → «Подтвердить результат»
   (`clerk_map.html:27-30,38-43,169,231-243`) → отдельное применение
   ночью/днём (`:251`, `:259`) не раньше разрешённой даты; при ручных
   изменениях — отдельное подтверждение замены
   (`settlement/apply.py:865-875`, флаг `:944`).

## 7. Общие правила экранов

1. Один экран — один владелец файлов (`WORKSTREAMS.md`); параллельная правка
   без владельца не начинается.
2. Новая функция экрана — отдельный JS-файл, а не дописывание в
   `driver-shift-v1.js`; файл подключается в шаблоне и попадает в
   `DRIVER_SCREEN_SCRIPTS` (`СИСТЕМА_MVP/backend/AGENTS.md:99-104`).
3. Версия оболочки поднимается вместе с правкой (`users/role_apps.py`,
   `users/views.py:286`) и в тестах.
4. Экраны без автообновления (`manual`): журнал, простои, транспорт, витрина,
   горные объёмы, планшетные отчёты, отчёты руководства
   (`state/audits/T-006/EVENTS.md:116-123`).
5. `210`/`211` — снимок 26.09.2026: номера строк и версии могут отставать, прав
   не устанавливают.

## 8. Что не проверено

Браузер, планшет, PWA-установка, drag-and-drop, фрагментное обновление,
realtime-опрос, звук, вибрация, фактические `403/409`, IndexedDB, service
worker, Android/APK, PostgreSQL, production, release SHA. Соответствие номеров
строк `211` текущему шаблону (6836) не сверялось.
