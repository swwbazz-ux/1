# QA ожидающих назначений v232

Проверено 13.09.2026 на локальном Django-контуре с ненулевым серверным сроком и
искусственными QA-назначениями, без производственных рейсов.

- 390x844 и 800x360: исходящий перевод с длинной целью, входящий перевод с длинным
  источником, назначение из свободных и снятие в свободные; таймер и подпись находятся
  внутри карточки, не пересекают изображение, номер, статус Водителя и индикатор связи;
  горизонтальное переполнение равно нулю.
- После серверного применения исходящие карточки 61/64 исчезли, входящие 62/63 стали
  обычными.
- При достижении нуля без сети все четыре карточки показали «Ожидает подтверждения».
  За 12 секунд offline выполнена одна попытка fragment-refresh; после восстановления
  сети выполнен один fragment-refresh, экран автоматически применил серверное состояние.
- Ошибок JavaScript и console error не зафиксировано.
