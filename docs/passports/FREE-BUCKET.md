# Паспорт механики: свободный ковш

- Статус: **черновик** (не утверждён владельцем). Дата: 2026-11-11.
- База: HEAD `63dc191e`, не release. Проверка: чтение кода и документов;
  тесты не запускались.
- Смежные: `TRIPS.md`, `SHIFTS.md`, `docs/guide/02` §5.

## 1. Назначение

Свободный ковш позволяет погрузить самосвал на экскаватор, к которому он не
назначен, не меняя основное назначение. Паспорт описывает выдачу разрешения,
срок жизни, погрузку по нему и известные ограничения.

## 2. Участники и права

| Роль | Действие | Условие |
|---|---|---|
| Экскаваторщик | принять, отменить, погрузить по ковшу | своя смена с экскаватором |
| Водитель | выбрать/отменить ковш, погрузиться | своя смена |
| Диспетчер | назначать технику (основной контур) | открытая смена диспетчера |
| Система | истечение срока | по TTL |

Доказательства: `trips/views.py:4362-4432` (погрузка);
`core/offline_sync.py:49-70` (события `*.free_bucket.*`).

## 3. Входы

- Модель принятия ковша: `occurred_at`, `cancelled_at`, связь с техникой и
  рейсом (`trips/free_bucket.py`).
- События офлайна: `excavator.free_bucket.accepted`, `.cancelled`, `.loaded`,
  `driver.free_bucket.selected`, `.cancelled` (`core/offline_sync.py:49-70`).
- Конфигурация: `EXCAVATOR_FREE_BUCKET_DUMP_CARD_SECONDS` (по умолчанию 300),
  `FREE_BUCKET_REQUEST_TTL_SECONDS` (по умолчанию 600)
  (`trips/free_bucket.py:17-25`).

## 4. Условия

1. Ковш действует, пока не истёк TTL и запись не отменена
   (`trips/free_bucket.py:58-60`).
2. Погрузка по ковшу не меняет основное назначение самосвала (правило
   владельца 26.09, п. 5; нормативной записи нет).
3. Один активный ковш на самосвал; новая выдача вытесняет прежнюю
   (`active_free_bucket_acceptance_for_truck`, `:89`).
4. Погрузка гружёного самосвала по ковшу не создаёт второй рейс.
5. Истёкшие разрешения закрываются сервером (`:106`, `:144-177`).

## 5. Сценарий и состояния

1. **Выдача.** Экскаваторщик принимает самосвал «свободным ковшом» → запись с
   `occurred_at` → событие версии.
2. **Выбор водителем.** Водитель видит предложение и выбирает его; событие
   `driver.free_bucket.selected` может уйти офлайн.
3. **Погрузка.** Погрузка по ковшу создаёт рейс; контекст берётся из снимка
   (`canonical_free_bucket_work_context_snapshot`, `:193`).
4. **Отмена.** Явная отмена или истечение TTL → `cancelled_at`; UI перестаёт
   показывать предложение.
5. **Истечение.** Периодическая сверка закрывает просроченные записи
   (`reconcile_expired_free_bucket_acceptances`, `:106`).

## 6. Ограничения и формулы

| Величина | Значение | Где |
|---|---|---|
| TTL запроса | 600 с (10 мин) по умолчанию | `trips/free_bucket.py:23-25` |
| Карточка «на разгрузку» | 300 с (5 мин) по умолчанию | `:17-19` |
| Активность | `occurred_at > now − TTL` и нет `cancelled_at` | `:58-60` |
| Один активный ковш | на самосвал | `:89` |

- **Т:** TTL — «дата только в коде» (T-006); решения владельца нет.
- **Р:** есть, значения читаются из настроек с указанными умолчаниями.
- **П:** нет.

## 7. Ошибки и офлайн

| Ситуация | Ответ | Где |
|---|---|---|
| Погрузка без своей смены | 403/409 | `trips/views.py:4406-4407` |
| Ковш истёк | предложение исчезает, погрузка — по обычным правилам | `:106-177` |
| Повтор события | `deduplicated`, второго эффекта нет | `core/offline_sync.py:3773-3798` |

Офлайн: принятие и отмена ковша поддерживаются очередью; погрузка по ковшу —
тоже. Терминальный `conflict` не имеет экрана решения (`docs/guide/06` §6).

## 8. Интерфейс

- Экскаваторщик: отдельный блок/кнопки ковша; погрузка не меняет карточку
  назначения.
- Водитель: предложение ковша в рабочем экране; основное назначение остаётся
  прежним (`docs/guide/07` §6).
- Диспетчер: видит последствия (рейс), отдельного экрана ковша нет.
