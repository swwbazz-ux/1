# Сигналы начала и завершения смены

Файлы `*_shift_start.wav` и `*_shift_end.wav` созданы внутри проекта
детерминированным цифровым синтезом. В них нет речи, музыкальных фрагментов,
чужих записей или сторонних сэмплов. Исходные MP3-файлы и материалы Warcraft
не используются ни в web-, ни в Android-сборках.

Генератор: `scripts/generate-shift-sounds.mjs`. Он создаёт одинаковые по байтам
копии каждого сигнала для Водителя и Экскаваторщика в двух контурах:

- `profiles/<role>/res/raw/` — Android resource;
- `СИСТЕМА_MVP/backend/static/audio/<role>/` — web/PWA resource.

Формат обоих сигналов: WAV, mono, 48 kHz, signed PCM 16-bit little-endian.
Пиковый уровень нормализован примерно до −1 dBFS без цифрового клиппинга.
Сигнал начала — три коротких одинаковых промышленных импульса; сигнал окончания
— два длинных нисходящих промышленных импульса. Рисунки специально различаются
по длительности, частотному диапазону и ритму, но не образуют мелодию.

Канонические SHA-256, фактические уровни, длительности и полный список копий
записаны в `audio/shift-sounds-manifest.json`. Воспроизводимая генерация:

- `shift_start`: `e0f6f86ea48c2ae9349889834435d3711a5811e82275c81e7417d87f23791cfb`;
- `shift_end`: `9a953e2a298a6eb5797c2cd95c5196060112f37a3899727ee8910ff3f9aba810`.

```powershell
node scripts/generate-shift-sounds.mjs
node --test tests/shift-sounds.test.mjs
```

Любое изменение байтов, WAV-параметров, громкости, длительности либо рассинхрон
между web и Android обнаруживается тестом.
